# BushiScraper

- A Bushiroad Decklog scraper that will take in a JP Shadvowverse Evolved decklog and convert it to an EN decklog (if possible) 

- Has internal functions to link together JP and EN cards, a review function to manually review cards that were close. and an Alternate ID function to sync all of the cards together in an undirected graph.

- Current plan is to write a frontend to interact with the main portion of the project (Giving a JP Decklog link, and converting it to an EN Decklog link => a Decklog that would work with other Shadowverse Evolved simulators).
